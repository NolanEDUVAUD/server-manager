# Signaler un problème

## Depuis l'application

**Paramètres → Signaler un problème** ouvre un formulaire de rapport de bug :

| Champ | Contenu |
|---|---|
| Titre | résumé court du problème |
| Description | ce qui se passe |
| Étapes pour reproduire | liste numérotée |
| Comportement attendu | ce qui devrait se passer |
| Comportement observé | ce qui se passe réellement |

Une case **Inclure les informations système** (cochée par défaut) ajoute au
rapport : version de l'application, système d'exploitation, langue et modules
activés.

> **Confidentialité**
> Le rapport ne contient **jamais** d'adresse IP, d'identifiants, de clés, ni
> de noms d'hôte — que la case « informations système » soit cochée ou non.

Deux façons d'envoyer le rapport :

- **Envoyer sur GitHub** : ouvre une issue **pré-remplie** dans ton
  navigateur, que tu peux relire et modifier avant de la publier — rien n'est
  envoyé automatiquement sans ta confirmation sur GitHub.
- **Copier le rapport** : copie le texte dans le presse-papier, pour le coller
  où tu veux (issue GitHub, message, etc.).

Si le navigateur ne peut pas être ouvert automatiquement, l'adresse de
l'issue pré-remplie peut être copiée pour être collée manuellement dans un
navigateur.

## Ouvrir une issue manuellement sur GitHub

Le dépôt du projet est
[github.com/NolanEDUVAUD/server-manager](https://github.com/NolanEDUVAUD/server-manager).
Pour ouvrir une issue sans passer par le formulaire de l'application, utilise
directement l'onglet **Issues** du dépôt. Avant d'en créer une, il est utile
de vérifier qu'un problème similaire n'a pas déjà été signalé.

## Soutenir le projet

**Paramètres → Soutenir le développement** rappelle que Server Power Manager
est un projet **gratuit**, développé sur le temps libre de son auteur. Si
l'application est utile, deux façons simples d'aider :

- **Faire un don** ;
- **Mettre une étoile sur GitHub**.

Une bannière de soutien discrète peut aussi apparaître ailleurs dans
l'application (voir [interface.md](interface.md#bannière-de-soutien)), avec
les options *Soutenir*, *Plus tard* ou *Ne plus afficher*.
